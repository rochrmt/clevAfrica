# CLEV Africa Consulting — Site vitrine

Front-end statique (HTML / CSS / JavaScript, sans dépendance) du site de CLEV Africa Consulting.

## Lancer en local

```bash
python3 -m http.server 8080
```

Puis ouvrir http://localhost:8080.

## Structure

- `index.html` — page unique (hero, à propos, expertises, approche, formations, galerie, références, bureaux, contact)
- `css/styles.css` — design system et animations
- `js/main.js` — interactions (révélations au scroll, curseur, effets magnétiques/tilt, galerie tactile, menu mobile, formulaire)
- `assets/` — logo, photos, logos des références
